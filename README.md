## ✨ Key Features

- 👟 **Product Catalog:** Categories (Men, Women, Kids, Sports, Casual) ke basis par shoes browse karein.
- 🔍 **Search & Filters:** Size, Color, Price Range, aur Brand ke hisaab se filter karein.
- 🛒 **Cart & Wishlist:** Shoes ko cart ya wishlist me add/remove karein.
- 🔐 **User Authentication:** Login, Sign up, aur JWT-based secure authentication.
- 💳 **Payment Gateway:** Razorpay / Stripe integration for safe and instant payment.
- 📦 **Order Management:** Users apne past orders aur order status track kar sakte hain.
- 📱 **Fully Responsive:** Mobile, Tablet, aur Desktop par seamless UI experience.
